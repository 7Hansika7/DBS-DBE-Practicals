# EYE OF ODIN - Frontend Client

3D WebGL Web Client for **EYE OF ODIN - Lost & Found Item Tracker for Campus**.

---

## 🚀 How to Run in VS Code

You can run this frontend in **any** of the following simple ways:

### Option 1: Live Server (VS Code Extension)
1. Open the `frontend` folder in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.

### Option 2: Built-in Python Server (Zero Install)
Open your VS Code integrated terminal and run:
```bash
python3 -m http.server 4200
```
Then open: **[http://localhost:4200](http://localhost:4200)**

### Option 3: Node / NPX
```bash
npx serve -l 4200 .
```

### Option 4: Direct Browser Open
Double-click `index.html` to view directly in Chrome, Safari, Edge, or Firefox!
